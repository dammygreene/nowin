# NOWIN Mascot Turnaround Assets

Original character-design reference poses for the NOWIN arcade creature. These are source artwork assets, separate from the cropped in-app hero file (`nowin-mascot.png`).

| File | View | Intended use |
| --- | --- | --- |
| `nowin-front.png` | Front / neutral confident stance | profile, UI reactions, front-facing key art |
| `nowin-three-quarter.png` | Three-quarter moving pose | game-card art, dialogue and promo placements |
| `nowin-back.png` | Back view with crown jacket emblem | turnarounds, animation planning, social art |
| `*-ui.webp` | Optimised UI derivatives | recurring in-app mascot reactions |

## Character anchors

- **Silhouette:** oversized orange-red arcade head, small body, oversized cyan shoes.
- **Hardware:** two yellow joystick-button antennae, small floating gold crown sticker.
- **Wardrobe:** lime varsity jacket, white gloves, hot-pink shorts/legs, cyan sneakers.
- **Expression:** clever, smug, playful—not hostile.
- **Ink/palette:** thick navy outlines; electric yellow, hot pink, cyan, lime, orange, and warm cream.
