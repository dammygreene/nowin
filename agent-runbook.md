# NOWIN Build Runbook

1. Maintain exactly six launch cabinets: Snake, Flap, Tetris, Cross, Pong, Tic-Tac-Toe.
2. Keep every betrayal deterministic, telegraphed, and beatable.
3. Keep demo/local data visibly distinct from production data.
4. Run unit tests, lint, typecheck, production build, and browser QA before release.
5. Only document winning strategies that were actually reproduced in a browser.
6. Never enable real payouts from the client.
