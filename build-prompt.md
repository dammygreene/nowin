# NOWIN Current Build Brief

Build a polished cartoony arcade with exactly six games: Snake, Flap, Tetris, Cross, Pong, and Tic-Tac-Toe.

Every game needs a finite win condition, deterministic learnable NOWIN betrayal, mobile controls, fast retry, local run record, and a genuine winning route. Production rewards must rely on a server replay verifier; the client is demo-only until that service exists.

Before declaring release readiness, run build, tests, lint, typecheck, and real browser/device QA. Do not represent demo data or local wins as global production data.
